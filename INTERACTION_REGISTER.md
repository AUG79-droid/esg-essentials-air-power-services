# Interaction Register

## Shared production behavior

All interactions must work with pointer, keyboard and touch. Drag-and-drop always has an equivalent “select item, then choose destination” control. State and feedback are conveyed through text, icons and position—not color alone. Required interactions persist compact state in localStorage; optional micro-interactions need persist only `visited/completed` when they contribute to a screen requirement. Incorrect choices explain the reasoning and permit retry. No interaction awards a numeric ESG or “green” score.

## Interaction completion language

Use “Activity completed” and “Review your reasoning.” Never display “passed,” “failed,” “ESG competent,” “certified” or a comparative learner ranking. A completed interaction can always be reopened in review mode.
