# Módulo 03 — Explicaciones visuales

## Visual 1 — Flujo de evidencia del reporte

**Objetivo:** Rastrear una métrica pública hasta sus registros y controles.  
**Elementos:** Fuente → responsable → definición → límite → método → cálculo → control → revisión → historial de cambios → divulgación/decisión del usuario; bucles de estimación, corrección y reformulación.  
**Idea clave:** La credibilidad de una cifra depende de su linaje y control, no del acabado visual.  
**Interacción:** Inspecciona puntos débiles y solicita evidencia.

## Visual 2 — Misma empresa, distinta calificación

**Objetivo:** Explicar la divergencia.  
**Elementos:** Un conjunto de evidencias entra en dos modelos con distinta finalidad, alcance, asuntos, ponderaciones, reglas para datos ausentes y grupos de pares; se obtienen resultados distintos.  
**Idea clave:** Compara lo que mide cada modelo antes que las puntuaciones.  
**Interacción:** Cambia una elección metodológica y observa la dirección del efecto, sin replicar un proveedor real.

## Visual 3 — Cadena afirmación-evidencia

**Objetivo:** Separar afirmación, métrica, objetivo y resultado.  
**Elementos:** Afirmación → límite/línea de base → métrica → datos/método → control/revisión → resultado; señales de alerta vinculadas a lagunas.  
**Idea clave:** Toda afirmación creíble necesita una cadena completa y proporcionada.  
**Interacción:** Construye la evidencia de las tres afirmaciones de APS.

## Visual 4 — Escalera de preparación para aseguramiento

**Objetivo:** Separar preparación de una conclusión de aseguramiento.  
**Elementos:** Criterios definidos → límite → método → evidencia conservada → controles → revisión → reproducibilidad → correcciones; carriles adyacentes comparan revisión interna, auditoría interna, verificación, certificación y aseguramiento externo.  
**Idea clave:** La preparación mejora la trazabilidad, pero no garantiza aseguramiento; alcances y conclusiones son distintos.  
**Interacción:** El alumnado identifica prerrequisitos ausentes y observa qué especialista debe decidir la norma y el nivel del encargo.
