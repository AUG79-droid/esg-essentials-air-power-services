# Módulo 06 — Explicaciones visuales

## Visual 1 — Cadena de gobernanza

**Objetivo:** Convertir en operativo `OBJETIVO → RIESGO → CONTROL → EVIDENCIA → SEGUIMIENTO → ESCALADO → ACCIÓN CORRECTIVA`.  
**Elementos:** Nodos conectados con retroalimentación desde acción correctiva hasta objetivo/riesgo; carril inferior de responsables y autoridad.  
**Idea clave:** Los vínculos ausentes crean falsa confianza.  
**Interacción:** El alumnado coloca elementos del programa en la cadena e identifica lagunas.

## Visual 2 — Mapa de autoridad y aseguramiento

**Objetivo:** Distinguir responsabilidad operativa, cuestionamiento especializado y aseguramiento independiente.  
**Elementos:** Consejo/alta supervisión, gestión, autoridad técnica, operaciones, riesgo, cumplimiento, calidad y auditoría interna; flechas etiquetadas decidir, ejecutar, asesorar/cuestionar, asegurar y escalar.  
**Idea clave:** Participar en una revisión no significa que cada participante aprobara todas las dimensiones.  
**Interacción:** Selecciona una decisión para revelar autoridad requerida. No se presupone estructura universal.

## Visual 3 — Matriz de eficacia del control

**Objetivo:** Separar diseño, ejecución y eficacia.  
**Elementos:** Columnas para riesgo abordado, adecuación de diseño, evidencia de operación, tendencia de resultados/excepciones, responsable y respuesta.  
**Idea clave:** Una lista completada puede coexistir con un control ineficaz.  
**Interacción:** Compara tres controles y diagnostica el tipo de fallo.

## Visual 4 — Vía de advertencia a escalado

**Objetivo:** Mostrar cómo puede diluirse la información.  
**Elementos:** Advertencia original → clasificación → cuadro de mando → revisión de gestión → autoridad → acción; ramas muestran información enterrada, rebajada, retrasada y en conflicto.  
**Idea clave:** La gobernanza de la información forma parte del control.  
**Interacción:** Restaura la advertencia y observa qué decisiones cambian.

## Visual 5 — Apetito de riesgo y restricciones no compensables

**Objetivo:** Distinguir decisiones gobernadas de riesgo de barreras obligatorias.  
**Elementos:** Capacidad → apetito → tolerancia → límite/desencadenante operativo; carril separado para seguridad, aeronavegabilidad, protección, prohibición legal, autoridad técnica obligatoria y restricciones graves de derechos.  
**Idea clave:** Un beneficio ESG ponderado no puede compensar el fallo de una barrera obligatoria.  
**Interacción:** El alumnado elimina opciones inviables, compara las restantes y dirige excepciones a la autoridad de escalado correcta.
