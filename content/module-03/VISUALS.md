# Module 03 — Visual Explainers

## Visual 1 — Reporting evidence pipeline

**Purpose:** Trace a public metric back to records and controls.  
**Elements:** Source → owner → definition → boundary → method → calculation → control → review → change history → disclosure/user decision; estimation, correction and restatement loops.  
**Takeaway:** A number’s credibility depends on lineage and control, not visual polish.  
**Interaction:** Inspect weak points and request evidence.

## Visual 2 — Same company, different rating

**Purpose:** Explain divergence.  
**Elements:** One evidence set enters two models with different purpose, scope, issues, weights, missing-data rules and peer groups; different results emerge.  
**Takeaway:** Compare constructs before scores.  
**Interaction:** Change one methodological choice and observe direction, without replicating a live provider.

## Visual 3 — Claim-evidence chain

**Purpose:** Separate claim, metric, target and outcome.  
**Elements:** Claim → boundary/baseline → metric → data/method → control/review → outcome; red flags attach to gaps.  
**Takeaway:** Every credible claim needs a complete, proportionate chain.  
**Interaction:** Assemble evidence for the three APS claims.

## Visual 4 — Assurance-readiness ladder

**Purpose:** Separate preparation from an assurance conclusion.  
**Elements:** Defined criteria → boundary → method → retained evidence → controls → review → reproducibility → corrections; adjacent lanes compare internal review, internal audit, verification, certification and external assurance.  
**Takeaway:** Readiness improves traceability but does not guarantee assurance; scopes and conclusions differ.  
**Interaction:** Learner identifies missing prerequisites and sees which specialist must decide the engagement standard and level.
