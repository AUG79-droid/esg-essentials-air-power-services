# Module 08 — Visual Explainers

## Visual 1 — Double-materiality decision matrix

**Purpose:** Move from context to a governed dual-lens judgment.  
**Elements:** Candidate issues flow through impact significance (scale, scope, irremediability, likelihood) and financial effect (magnitude, timing, likelihood); either-lens inclusion rule, evidence/uncertainty flags, threshold and validation gate.  
**Takeaway:** Impact and financial materiality are related but not identical; a matrix supports rather than replaces judgment.  
**Interaction:** Learner tests inclusion/exclusion, records evidence and sees why a severe impact cannot be averaged away.

## Visual 2 — Strategy implementation chain

**Purpose:** Connect issue to outcome.  
**Elements:** issue → objective → owner → action → evidence → indicator → threshold → review → correction.  
**Takeaway:** Missing ownership or causal link turns ambition into reporting.  
**Interaction:** Build the chain for responsible sourcing.

## Visual 3 — Activity/performance distinction

**Purpose:** Teach the four non-equivalences.  
**Elements:** input, activity, output, outcome, impact, with target and metric attached at different levels.  
**Takeaway:** Completion of work does not prove the desired change.  
**Interaction:** Classify supplier-audit and energy-retrofit measures.

## Visual 4 — Project lifecycle gates

**Purpose:** Place ESG evidence in existing work.  
**Elements:** concept, requirements, design/source, approval, delivery, acceptance, operation, end-of-life; each gate shows question, evidence, authority and escalation.  
**Takeaway:** Early integration preserves options and avoids parallel bureaucracy.  
**Interaction:** Drag evidence to the earliest useful gate.
