# Module 08 — Interactive Activity: From ESG to Action

## Scenario

The learner receives the broad statement “Improve responsible sourcing” in an **AIR POWER SERVICES LEARNING SCENARIO**.

## Task and actions

Define purpose and scope; build a candidate issue list; assess impact and financial materiality separately; document evidence, threshold and inclusion/exclusion; choose objective and owner; select actions; construct leading, lagging, output and outcome indicators; set review trigger and escalation criterion; place each requirement in an existing process gate.

## Feedback

Audit counts treated as outcome trigger the activity/performance distinction. An objective without boundary prompts scope. A metric without response prompts decision-usefulness. A new parallel committee prompts integration. A single aggregate score cannot offset severe rights or mandatory technical issues. Overconfident targets reveal uncertainty and resource dependencies.

Requiring an issue to pass both materiality lenses is corrected: under double materiality it may qualify through either lens. Mechanically multiplying uncertain scores triggers a request for documented judgment and sensitivity.

## Expected outcome

A complete, causal and governed implementation chain that can be tested and corrected.
