# ESG ESSENTIALS

## Environmental, Social & Governance for Air Power Services

### From Principles to Better Business Decisions

ESG Essentials is a premium, browser-based learning experience that helps Air Power Services colleagues connect environmental, social and governance considerations to evidence, impacts, affected people, uncertainty, authority and action.

- Approximately **7 h 39 min** of guided learning.
- **10 modules**, from ESG foundations to an integrated capstone.
- An eight-stage **Decision Lab** that makes trade-offs, evidence, escalation and monitoring visible.
- Local-only learner progress stored in the browser on the learner’s device.
- Static browser application: no backend, login, personal-data collection or analytics.

This is an educational learning experience. It is **not** certification, qualification, or technical, legal or company authorization.

## Local development

This project uses Vite, React and pnpm.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run lint
pnpm run build
pnpm dev
```

The application uses hash routing so static hosting can serve all learner routes without a backend.
